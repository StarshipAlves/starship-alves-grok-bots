# Starship Alves Grok Bots

Shareable Grok Bot setups by Starship Alves. Each bot has its own folder with everything you need to recreate it. None of them include personal data.

## Bots

| Bot | What it does | Folder |
|---|---|---|
| Tax Man | Finds invoices and receipts in your Gmail and sorts them into a categorized tax-prep spreadsheet | [tax-man](tax-man/) |
| Email Detective | Sorts your Gmail weekly, flags likely spam, and asks before sending anything to spam or unsubscribing | [email-detective](email-detective/) |

More bots coming soon.

## How to use a bot
1. Open the bot's folder.
2. Use its template link if there is one, **or** create a new Grok Bot and paste the contents of `instructions.md` as its description.
3. Connect the services listed under **Needs**.
4. Send it the first task from `first-task.md`.
